Publishing

Alerts are retained messages on alerts/<source>/<id> with a JSON body {"level": "info|warning|critical", "title", "message", "since": <epoch s>, ...}; an empty retained message on the same topic clears the alert. Clients announce themselves on status/<name> (online, with offline as their last will).

Services and devices (Pis, NodeMCUs...) connect to port 1883 on this PC from the LAN or tailnet, each with its own login: node serve.mjs mqtt-user <name> in the webserver folder (restarts the broker so it works at once). Every login reads alerts/#, devices/# and status/#, and writes only its own alerts/<name>/…, devices/<name>/… and status/<name> (mqtt/acl.conf). This page is read-only.

mosquitto_pub -h <this PC> -u <name> -P <password> -r -t alerts/<name>/test -m '{"level":"info","title":"Test","message":"Hello"}'
mosquitto_pub -h <this PC> -u <name> -P <password> -r -t alerts/<name>/test -n     # clear it
mosquitto_sub -h <this PC> -u <name> -P <password> -t 'alerts/#' -v              # watch alerts
